UX del Subdominio

Mientras el usuario escribe el nombre del negocio, se genera automáticamente un slug. Se muestra como mi-negocio.aldia.com.pe. La disponibilidad se verifica con un debounce vía GET /api/check-subdominio, mostrando indicador visual:

  • Gris — esperando entrada
  • Amarillo — verificando
  • Verde — disponible
  • Rojo — ocupado o reservado

Medidor de Fortaleza de Contraseña

Barra de progreso con 4 niveles: Muy débil, Débil, Buena, Fuerte. Colores: rojo, naranja, amarillo, verde.

UX Post-registro

Mensaje de éxito verde: “Cuenta creada exitosamente” y reseteo del formulario.

4. Dashboard — /dashboard.html

Pantalla de Login del Dashboard

Diseño centrado con tarjeta blanca. Campos: Email y Contraseña. Botón “Ingresar”. Mensajes de error inline.

Panel de Administración de Productos

Una vez autenticado, el dashboard muestra:

  • Header: logo ALDIA, nombre del negocio, botón “Cerrar sesión”
  • Formulario de producto: Nombre, Descripción, Precio, Stock, Categoría + botón “Agregar producto”
  • Tabla de productos: columnas ID, Nombre/Desc, Precio, Stock, Categoría, Acción (Eliminar)
  • Estados vacíos: “Todavía no tenés productos. Agregá tu primer producto arriba.”

UX de operaciones CRUD

  • Crear: formulario → POST /api/products → refresca tabla
  • Leer: GET /api/products al cargar y tras cada operación
  • Eliminar: confirm() del navegador + DELETE /api/products/:id

7. Flujo de Navegación UX

Landing → Registro → Dashboard → CRUD Productos
Landing → Login → Dashboard → Ver datos

Recorrido típico del usuario

  1. Llega al landing y lee la propuesta de valor en el hero
  2. Explora las secciones de beneficios, cómo funciona, precios
  3. Hace clic en “Crear cuenta gratis” (hero, nav, plan) y es llevado al formulario de registro (#registro)
  4. Completa el registro con validación en tiempo real del subdominio y fortaleza de contraseña
  5. Recibe confirmación y luego inicia sesión vía #login
  6. Accede al dashboard donde puede gestionar productos (alta, baja, consulta)
  7. Usuario existente ingresa directo por #login desde cualquier botón “Iniciar sesión”

Puntos de entrada a Login

  • Nav desktop: “Iniciar sesión”
  • Nav mobile: “Iniciar sesión”
  • Hero section: botón ghost “Iniciar sesión”
  • Sección CTA: “Iniciar sesión”
  • Formulario de registro: link “¿Ya tenés cuenta? Iniciar sesión”
